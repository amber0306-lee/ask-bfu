# 来源、有效期与纠错规则

## 来源分层

| 级别 | 例子 | 用途 | 回答时标注 |
|:--|:--|:--|:--|
| A | 学校正式文件、当年培养方案、学院正式细则 | 资格、流程和制度判断 | 文件名、文号或版本、适用范围、原文链接 |
| B | 校院官网公告、主管部门通知 | 校历、招生、办事时间 | 发布日期、执行日期、主管部门 |
| C | 学生经验、经核实的周边商户 | 路线和生活建议 | “经验信息”、核验日期及变化可能 |

个人上传的手册可用于核对；要先记录版本及适用年级，再决定能否公开摘要。无法确认是否公开发布时，不把整本手册或未公开附录写入仓库。

## 查询决策

| 用户问法 | 先做什么 | 答案边界 |
|:--|:--|:--|
| “2024年修订的细则规定多少？” | 读仓库事实卡并直接答 | 明示2024版，不声明2026年仍未变化 |
| “现在/今年多少钱？” | 先读事实卡，再针对金额查当前官方文件或公告 | 若未找到更新，说明已核对范围和所依据的旧版 |
| “今年什么时候放假、报名、评审？” | 查当期校历或主管部门公告 | 不从往年日程推测 |
| 仓库没有覆盖的事项 | 搜学校/学院官网，再考虑可核验经验 | 未核实则直说 |

## 时效判断

- 招生、校历、放假、开学、课时、复试、奖助：遇到“今年/当前”时仅核对相关年度的主管部门公告；同轮已核实的同一文件可直接复用。无法查证时不提供确定日期。
- 培养和毕业：先确定学生入学年份及培养层次，再核对适用文件和学院补充规定。文件修订不意味着旧年级自动适用新版。
- 地址、电话、营业时间：在回答具体路线或服务前核对最近公开资料；标明最后核验时间。
- 已知旧文件可给历史背景，但不可充作当前规则。

## 答案样式

简单事项：**结论**；**怎么做**；**来源（发布/核验日期）**。

条件复杂事项：用短表格列“项目、目前掌握的事实、待核对材料”，追问只限真正影响结论的字段。

若校级与院级文件似乎矛盾，先核对适用对象、文件效力与发布日期；仍不清楚时列出两个来源并建议询问具体主管办公室。不得暗自替学生判定资格。

## 添加条目时

建议每条记录使用编号、问题、精确事实、发布单位、文件版本/发布日期、适用人群/年级、原始网址、最后核验日期。生活经验再加“实地/电话/公开页面”的核验方式。失效链接或事实变化可在 GitHub Issue 提交原始出处和修改理由。
