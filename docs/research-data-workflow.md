# 论文与数据采集工作流程

本流程仅在用户提出论文、数据搜集或核对任务时使用；不改变 Ask BFU 的校园问答定位。

## 输入与续接

先检查原始表、变量说明、样本期、研究层级、地区编码、审稿意见及已有补数记录。既有聊天记录与文件不自动跨任务共享。缺少输入时，列明实际缺失项，不根据聊天标题猜测数据定义。

在私人工作目录维护：
- TASK_BRIEF.md：问题、目标、已确认口径和交付要求。
- DATA_DICTIONARY.md：变量名、含义、单位、来源和构造方式。
- PROGRESS.md：已完成、证据位置、未解决项和下次起点。
- raw/：原始资料，保留原件。
- work/：脚本、中间结果和日志。
- outputs/：日期或版本命名的主表、核对表和说明。

这些文件只在用户本次私人任务空间生成，不提交本公开仓库。

## 搜集与来源登记

优先统计部门、政府主管部门、官方年鉴和正式政策原文。核对省级/市级、统计年度/出版年度、人数/人次、期末/全年、金额单位及口径变更。

来源登记至少包括：变量、地区、年份、原始值、单位、标题、发布机构、原文链接、表号或页码、访问日期、处理规则、核实状态。网页不可达时保留失败记录，并继续查询官方替代来源。

政策指标须先确认编码规则，再从候选文件形成最终指标；记录发文日期、生效日期、文件层级、重复与修订关系。候选文件数量不得直接冒充最终政策指标。

知网等检索指标须记录检索库、字段、精确检索式、年份、检索日期、命中数和去重规则。搜索引擎估计数、另一数据库计数不能冒充知网计数。遇到登录、验证码或权限限制如实记录。

## 清洗与缺失

交付主结果表和核对表，核对重复键、缺失、匹配率、异常值、单位、样本期、剔除规则、缩尾和滞后变量。

保留 raw_value 与 processed_value，并用 status 区分 observed、derived、imputed、missing。插值需记录方法、范围和原因，保留未插值版本；分类事件、政策出台与不可合理连续化的变量不做机械插值。不根据期望回归结果填值或抹平真实变化。

## 回归衔接

当前环境有 stata-runner 时优先读取其技能。本地 Stata 的 Windows 路径不代表云端可用；云端无真实可用的 Stata 时可整理数据和生成 .do，但必须注明未执行。

.do 包含 clear all、set more off、明确 cd 和日志。核对个体固定效应、年份效应、聚类标准误、控制变量、有效样本及组内 R2。表格优先可编辑 RTF/Word。没有实际执行不可宣称回归完成。

## 交付核验

检查输出文件存在且非空、脚本退出码、表行列、键唯一性、缺失和来源覆盖。写明哪些是已核实数据、哪些是估算、哪些仍缺失。公开资料与私人研究材料分别保存。
